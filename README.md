# holoshop-enhance

hololive production 官方商店（<https://shop.hololivepro.com/>）的個人用 Chrome 擴充功能，幫你：

- 把想買的商品加入**最愛**，集中查看截止時間；
- 在商品頁直接看到**自己買過幾件**（含各規格數量）；
- 快截止又還沒買的最愛，在擴充圖示上用**數字提醒**。

所有資料只存在你的電腦上，不會上傳到任何伺服器。

> 本擴充功能為**非官方**工具，**僅限個人使用**，與 hololive production 及商店營運方無關。

## 功能

### 商品頁

- **最愛按鈕**：商品標題下方的愛心，點一下加入／移除最愛。未登入時無法使用。
- **已購買標示**：買過的商品會顯示「購入済み N 点」，並在各規格旁顯示數量（部分版型改在標示下方列出）。已取消的訂單不計入。

### 最愛清單（Side Panel）

點擴充圖示即開啟，上方切換「お気に入り（N）」「注文（N）」分頁；N 為目前篩選條件下顯示的件數。

- 顯示縮圖、商品名稱、截止時間（JST）與剩餘天數；快截止的會醒目標示。
- 分頁篩選：未購買（預設）／已購買／全部。
- 已截止又沒買的商品會反灰，預設隱藏，可勾選「顯示已截止」查看。
- 每件商品可單獨「停止提醒」或移除。

### 訂單（Side Panel）

Side Panel 上方切換到「注文（N）」分頁，可用「未発送／発送済み／すべて」篩選。

- 「未発送」（預設）：還沒出貨或部分出貨的訂單，不分年份，依発送予定日由舊到新排列；沒有日期的排在最後。
- 「発送済み」「すべて」：右側可選年份，依注文日由新到舊排列；「すべて」也會列出已取消的訂單（反灰）。
- 每筆顯示発送予定日與剩餘天數（已超過時以紅字顯示「N 日超過」）、注文日、注文番号、品項縮圖與數量、合計金額，以及訂單詳細頁連結。
- 「11月下旬」這類模糊日期，以該期間的最後一天計算。
- 訂單出貨後，下次同步時會從「未発送」移到「発送済み」。

### 購買統計

點 Side Panel 右上角的統計圖示（齒輪左邊），在新分頁開啟。

- 依年或月統計消費金額（訂單合計，含運費；不含已取消的訂單）。
- 每種幣別分欄列出，只顯示該期間出現過的幣別；最後一欄換算成你選的合計幣別（預設 JPY）。
- 匯率內建粗略的預設值，可在「為替レート設定」自訂，或恢復預設。
- 「タレント別」分頁：依商品小計（不含運費與稅金）統計，分成タレント（單人商品）、ユニット（組合、2 人、同期別）、グループ（地區與多人商品）、その他四類，可切換顯示或全部顯示，並可依年份篩選。
- 點任一列可查看該列的商品明細（縮圖、名稱、平均單價、數量、合計；同商品同規格會合併），按「戻る」或瀏覽器的上一頁返回。
- タレント別統計需要每筆訂單的明細，同步時會逐一讀取訂單詳細頁；第一次會比較久，尚未讀取的訂單數會顯示在統計頁下方。

### 截止前提醒

- 最愛中**未購買**、且在截止前 N 天內（預設 7 天）的商品數量，會以橘色數字顯示在擴充圖示上；滑鼠移上去可看到件數。
- 天數可在設定頁調整（1–30 天）。

### 訂單同步

- 只要開著任一商店頁面並已登入，擴充功能就會在背景讀取「マイアカウント」的訂單紀錄，用來計算已購數量。
- 第一次會讀取全部訂單（訂單多時可能需要十幾分鐘，期間圖示顯示百分比）；之後只讀取新的訂單，以及到最舊一筆未発送訂單為止的頁面（用來更新出貨狀態）。
- 同步期間可以正常瀏覽商店。關閉分頁會暫停，下次開啟商店頁面時從中斷處繼續。
- 需要重新登入時，圖示會顯示紅色「!」。
- 擴充功能只會讀取頁面，**不會**替你加入購物車、下單或修改任何帳號資料。

### 商品列表

- 在商品列表（例如「全商品」）捲到接近底部時，會自動載入更多商品，不用再按「もっと見る」。
- 可在設定頁關閉。

### 數位內容列表

- 從「マイアカウント」的「デジタルコンテンツリスト」進入時，會自動把所有分頁的項目合併到同一頁。
- 列表上方有搜尋框：用空白分隔多個關鍵字，全形／半形、大小寫都可以；會顯示符合的件數。

### 多帳號與多語系

- 不同的商店帳號，資料完全分開。
- 介面支援日文（預設）、英文、繁體中文；預設跟隨商店網頁的語言，也可以在設定頁固定。

### 設定頁

Side Panel 右上角的齒輪，或在擴充圖示上按右鍵 →「選項」。

- 表示語言、截止前天數、在圖示顯示同步狀態、商品列表自動載入。
- 立即同步／全部重新同步。
- **匯出／匯入**：把最愛、訂單與用到的商品資訊存成 JSON 檔備份，或從備份檔還原（本機較新的資料不會被覆蓋）。還原後不需要重新取得商品資訊；舊的備份檔缺少的部分會在下一次同步時自動補齊。
- **帳號管理**：修改帳號的顯示名稱、刪除某個帳號的所有資料。

## 安裝

本擴充功能未上架 Chrome Web Store，需以「載入未封裝項目」安裝。

### 方法一：下載發佈版（建議）

1. 到 [GitHub Releases](../../releases) 下載最新版本的 `holoshop-enhance-<版本>-chrome.zip`。
2. 解壓縮到固定的資料夾（之後不要移動或刪除）。
3. 開啟 Chrome 的 `chrome://extensions`，打開右上角「開發人員模式」。
4. 按「載入未封裝項目」，選擇解壓縮後的資料夾（裡面有 `manifest.json`）。
5. 開啟 <https://shop.hololivepro.com/> 並登入。

更新版本時，下載新版 zip 解壓縮覆蓋原資料夾，再到 `chrome://extensions` 按擴充功能上的「重新載入」。資料存在瀏覽器中，覆蓋檔案不會遺失。

### 方法二：自行建置

1. 安裝 [Node.js](https://nodejs.org/) 與 pnpm（`npm install -g pnpm`）。
2. 在專案資料夾執行：

   ```bash
   pnpm install
   ```

   ```bash
   pnpm build
   ```

3. 開啟 Chrome 的 `chrome://extensions`，打開右上角「開發人員模式」，按「載入未封裝項目」，選擇專案資料夾中的 `output/holoshop-enhance`。

更新版本時，重新執行 `pnpm build`，再到 `chrome://extensions` 按擴充功能上的「重新載入」。

## 隱私

- 資料只存在瀏覽器本機（IndexedDB 與擴充功能儲存空間）。
- 只會連線到 `shop.hololivepro.com`，不包含任何分析或追蹤。
- 不儲存姓名、地址、Email；訂單只保留顯示與計算所需的欄位（訂單號、日期、狀態、発送予定日、品項、縮圖、數量、金額）。

## 已知限制

- 商店網站改版時，部分功能可能暫時失效。
- 沒有開著商店頁面的期間不會同步訂單；在其他裝置購買後，要等下次開啟商店頁面同步才會反映。
